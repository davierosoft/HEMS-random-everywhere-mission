# Basepack

The sound content of the mission pack (`hpg-airbus-h145-z-andrew-mission-pack`, mission 0.997), in the same folder structure as the pack that is installed in the Community folder. It is the one source of the mission sounds: the Mission Companion installs missing or changed files (wav and `sound.xml` / `soundai.xml` entries) from here, and a first installation downloads them from this repository instead of from a file host.

## Content

| Path | Content |
| --- | --- |
| `Simobjects/Airplanes/hpg-airbus-h145-ems/Sound/` | All `AND.*.wav`, `H145.*.wav` and the other mission sounds of the H145, and its `sound.xml`. Includes the crew crash sounds `AND.crash.*.wav` (played by the Companion, no `sound.xml` entry). |
| `Simobjects/Airplanes/<other model>/(Soundai\|soundai)/` | `soundai.xml` and the wav of each mission object (ambulances, police, fire trucks, injured person, satellite dish, DarkOps, 30West humans). |
| `manifest.json` | Package manifest of the pack. |

Not part of the basepack: the mission files (`everywhere_all.json` and `train.json` are in the repository root and are the only current ones), `layout.json` (generated by the Companion or by the layout generator after files are added), changelog and notes.

## Rules

- A new or changed sound is added here, in the folder of the model that plays it; the newest file wins. Names are runtime identifiers: never rename a wav that a `sound.xml` entry or a pack message refers to.
- File bytes must stay as they are (`.gitattributes` marks this folder as not text): the Companion compares the git blob hash of the local files with the one of this repository, so a normalised line ending would show every xml as changed.
- The folder `sound/` of the repository root was moved here (history kept with `git mv`).
